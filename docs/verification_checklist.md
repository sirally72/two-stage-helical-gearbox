# Verification Checklist

Use this checklist before describing the project as verified. Mark items only after completing the work.

- [ ] Run the Python script and review every printed value.
- [ ] Independently verify speed, torque, ratio, module conversion, and centre distances.
- [ ] Resolve the difference between report estimates and script output, if any.
- [ ] Define duty cycle, load spectrum, service factor, and target life.
- [ ] Select gear material, hardness, quality grade, and lubricant.
- [ ] Complete gear tooth-root and contact stress calculations using a recognized method.
- [ ] Calculate radial and axial loads with directions based on rotation and helix hand.
- [ ] Check shafts for combined bending/torsion, fatigue, deflection, and critical speed.
- [ ] Select bearings and verify life and static capacity using catalogue data.
- [ ] Define keys/splines, fits, tolerances, seals, fasteners, and housing split.
- [ ] Check CAD dimensions and interference; do not use smooth blanks as real gear geometry.
- [ ] Add figures, revision history, references, and a bill of materials.
- [ ] Have a qualified engineer review the design before fabrication or operation.
